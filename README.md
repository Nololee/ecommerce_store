# ecommerce_store# E-Commerce and Online Shopping Platform

## Project Overview

This project is an online shopping platform that allows
customers to browse products, add items to their cart,
make purchases and track their orders.

## Technologies Used

- Laravel (Backend)
- React.js (Frontend)
- PHP
- MySQL (Database)
- HTML, CSS and JavaScript
- Git and GitHub

## Main Features

- Customer registration and login
- Product catalogue
- Product categories
- Product search
- Shopping cart
- Checkout
- Payment gateway integration
- Order tracking
- Inventory management
- Admin dashboard
- Sales reports

## Installation

1. Clone the repository.
2. Install PHP dependencies:

    composer install

3. Install JavaScript dependencies:

    npm install

4. Create your environment file:

    copy .env.example .env

5. Generate the application key:

    php artisan key:generate

6. Configure your MySQL database in the .env file.

7. Run database migrations:

    php artisan migrate

8. Start the Laravel server:

    php artisan serve

9. Start the frontend:

    npm run dev
